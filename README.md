# 日本旅行先ルーレット

インタラクティブなサイコロを振って、日本の旅行先を決めるアプリケーションです。

## 使い方

1. **[アプリケーションを開く](https://Ginoinjpn.github.io/travel-roulette/)**
2. **「地方を振る」ボタンをクリック** — 6つの大地方からランダムに1つ選択されます
3. **「都道府県を振る」ボタンをクリック** — 選択された地方の6つの区分から1つ選択されます
4. **「市町村を振る」ボタンをクリック** — 市区町村レベルの目的地が決まります

## 特徴

- 🗾 **1,894の市区町村** — 日本全国の市区町村境界をGeoJSONデータから生成
- 🎲 **3段階のランダム選択** — 地方 > 都道府県 > 市町村の階層的なルーレット
- 🗺️ **インタラクティブな地図** — サイコロを振るたびに地図がズームして表示
- 📍 **ピンポイント表示** — 最終的な目的地には赤いピンが表示されます
- 📋 **履歴記録** — 過去の旅行先の結果をブラウザに保存（最大20件）
- 🔢 **出目のガイド表示** — 振る前の地図に、どの目がどこを指すかを示す数字を薄く表示（1個目=赤／2個目=黒／3個目=青）
- 🏘️ **対象市町村の一覧** — 行き先が決まると、地図の下にその範囲の市町村名をすべて表示

## データ構造

6地方 × 6区分 × 6区分 = 216通りの行き先を持ちます。

| 段階 | UI上の呼び方 | 実際の区分 |
| --- | --- | --- |
| 1個目 | 地方 | 北海道／東北／関東・甲信越／東海・北陸／近畿・中国・四国／九州・沖縄 |
| 2個目 | 都道府県 | 都道府県、または隣接県のまとまり（北海道のみ道南・道央などの地域区分） |
| 3個目 | 市町村 | 2個目の区分内の市区町村を地理的に6分割したもの。代表市区町村名で表示 |

UIでは分かりやすさを優先して「都道府県」「市町村」と表記していますが、実際には上表のとおり
複数県のまとまりや複数市区町村のまとまりを含みます。
区分は、地図SVGに含まれる市区町村の重心座標から機械的に生成しています。
名称は総務省の全国地方公共団体コードに基づく市区町村名を使用しています。
北方領土の6村は地図上には表示されますが、抽選対象からは除外しています。
